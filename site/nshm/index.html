Section Overview

An installable nshm is not merely any crate prefixed with nsh- or tagged with keywords = ["nshm"] on crates.io. According to crates/nsh-cli/src/nshm/manifest.rs in longbridge/nsh, nsh add accepts a package only when it matches one of four structural manifest layouts—Rust (#[native_module("...")]), pure TSX (nsh.json "exports"), Hybrid (both), or Platform ("platform": "<target>")—and satisfies semver checks against nsh 0.7.1.

This hub consolidates the 13 cleanly compatible modules verified across crates.io (7 modules plus 40 grouped icon-pack companion crates), github:owner/repo checkouts (5 modules), and Git branch pins (1 module). Unverified 0.6-era crates that only slip through nsh add because of Cargo's [dependencies.nsh-core] table normalization parser quirk are intentionally excluded here and documented on the Discovery page.

Grouped Icon Companion Crates & Version-Pin Workarounds

To keep the directory readable instead of flooding listings with 40 repetitive sub-crates, the 5 icon packs under nsh-icon and the 35 Iconify set crates under supernsh-icons are documented inside their parent module pages. Note also that nsh-widgets and nsh-platform-harmonyos currently require GitHub sources (--rev master and github:huacnlee/nsh-platform-harmonyos respectively) because their published crates.io versions either pin nsh: ^0.6 or lack the platform key.

Practical Module Selection Guidance

UI Kits: nsh-omarchy vs nsh-shadcn

Pick nsh-omarchy (0.2.0) when you want an established crates.io release with Omarchy desktop theme synchronization, Tokyo Night or Flexoki Light defaults, and built-in charts. Consider nsh-shadcn as an early 0.1.0 option if your team specifically wants new-york-v4 styling, Chat UI primitives, or .app_class(...) overrides while accepting its partial Navigation Menu and Sidebar caveats.

Icons: nsh-icon vs supernsh-icons

Choose nsh-icon when one of the five major MIT/Apache sets covers your app with minimal dependencies. Choose supernsh-icons when you need brand logos, country flags, specialty Iconify packs from 260 sets, or compiled .ttf glyph fonts—remembering that --target web needs LLVM clang and llvm-ar.

Graphics & Telemetry: nsh-graph, nsh-o11y, nsh-webgpu, nsh-skia

Use nsh-graph for topology diagrams and nsh-o11y for metrics, logs, traces, and flame graphs on NSH's built-in <Canvas>. Reach for nsh-webgpu when porting WebGPU shaders across desktop/mobile/web, or nsh-skia when you specifically need react-native-skia 2D paths and shaders on macOS and Linux.
