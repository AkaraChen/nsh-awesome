# nsh-icon

> Tree-shaken vector icon renderer (`<Icon>` and `icon()`) paired with five installable icon-set crates (Lucide, Heroicons, Tabler, Phosphor, Remix).

## Installation & Verification

```bash
nsh add nsh-icon
```

Verified with `nsh add` in a clean scratch app on `nsh 0.7.1` (install resolution only; does not claim full cross-platform on-device compilation).

## Implementation Notes

Install companion icon packs alongside it, e.g. `nsh add nsh-icon-lucide`, `nsh-icon-heroicons`, `nsh-icon-tabler`, `nsh-icon-phosphor`, `nsh-icon-remix`.
