# supernsh-icons

> Typed SVG and font-glyph icon library covering 260 Iconify sets (~465,000 icons) with 35 installable companion set crates.

## Installation & Verification

```bash
nsh add supernsh-icons
```

Verified with `nsh add` in a clean scratch app on `nsh 0.7.1` (install resolution only; does not claim full cross-platform on-device compilation).
