Section Overview

End-user Native Shell applications built in mixed Rust and TypeScript TSX mode look remarkably similar to Rust nshm crates on disk because their src/lib.rs also exports #[native_module("...")] symbols. However, inspection on nsh 0.7.1 confirms that repositories such as SuperNSH/starter, huacnlee/spotish, and ryujane/Ferrix configure publish = false in Cargo.toml and declare "root" or "id" in nsh.json instead of "exports"—meaning they are complete applications to clone and adapt rather than libraries to add with nsh add.

Awesome NSH isolates these 4 starter, example, reference-app, and showcase repositories (longbridge/nsh Examples, SuperNSH/starter, longbridge/nsh-showcases, and huacnlee/disktree) into a dedicated hub so newcomers can bootstrap desktop, mobile, or Web projects without mistaking full app templates for installable nshm dependencies.

App Boilerplate vs Installable `nshm` Manifest Signatures

An installable library declares "exports" (for tsx-nshm or hybrid-nshm) or "platform" (for platform-nshm) in nsh.json without claiming an application "id" or "root" component. By contrast, application templates carry "entry" or "root" keys ("root": "App" in SuperNSH/starter), bundle identifiers, and app-local ext/ Rust crates compiled inside the project itself rather than locked via nsh.lock.

Picking the Right Starting Point for Your Project

Learning core Native Shell idioms: start with longbridge/nsh Examples

Because official examples live directly inside longbridge/nsh/examples at 0.7.1, every pattern—from pure Rust tasks-rs to mixed rust-exports, tray menus, host embedding, and nsh-extra integration—stays synchronized with the 0.7.1 CLI release and nsh.dev/gallery.

Bootstrapping a multi-screen TSX app: inspect SuperNSH/starter

SuperNSH/starter (0.1.0) targets nsh 0.7.1 across macOS, iOS, Android, and Web, showing how multi-screen navigation, form inputs, virtualized lists, native animations, and signed .nshpkg remote TSX packages fit together cleanly.

Adding app-specific Rust code without publishing an nshm: study huacnlee/disktree

Not every Rust helper belongs on crates.io. huacnlee/disktree (macOS, Linux) pairs a responsive TSX treemap interface with a fast local Rust disk scanner via ext/, serving as the official reference for mixed app projects.
