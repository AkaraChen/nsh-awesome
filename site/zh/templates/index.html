Native Shell 示例集合、脚手架模板与参考应用

面向 nsh 0.7.1 的工程起点导航：汇总官方示例、生产风格 TSX 应用模板、本地 ext/ 混合模式真实案例以及官方社区 Showcase 仓库。

板块概述

采用“TSX 界面 + 本地 Rust 扩展”混合架构的端到端 Native Shell 应用，在 src/lib.rs 中同样经常包含 #[native_module("...")] 导出宏，表面结构与独立 nshm 库非常接近。但基于 nsh 0.7.1 核验后可知，像 SuperNSH/starter、huacnlee/spotish、ryujane/Ferrix 这类项目配置了 publish = false 并在 nsh.json 中声明 "root" 或 "id" 而非 "exports"，它们属于可直接克隆改写的完整应用模板，不能作为库通过 nsh add 安装。

因此 Awesome NSH 将 4 个模板、示例与参考应用（longbridge/nsh Examples、SuperNSH/starter、huacnlee/disktree 与 longbridge/nsh-showcases）单列为独立分区，既方便开发者迅速起步，也防止初学者误对整站应用仓库执行 nsh add。

应用模板与可安装 `nshm` 库的清单区别

可复用 nshm 库会在 nsh.json 暴露 "exports"（tsx-nshm / hybrid-nshm）或 "platform"（platform-nshm），不携带应用级 "id" 与 "root"；而应用模板在 nsh.json 定义入口组件（如 SuperNSH/starter 中的 "root": "App"）、应用包名以及随工程一起编译的本地 ext/ 目录，直接用 git clone 获取即可运行。

工程起步路线建议

对照框架基准写法：先看 longbridge/nsh Examples

官方示例随 longbridge/nsh 0.7.1 同步更新，适合核对纯 Rust tasks-rs、混合 rust-exports、系统托盘与宿主嵌入等标准用法。

搭建多页面 TSX 应用脚手架：参考 SuperNSH/starter

需要导航栈、长列表虚拟化、表单交互与已签名 .nshpkg 远程 TSX 加载实践时，可直接对照 SuperNSH/starter 的目录结构组织代码。

项目内嵌专用 Rust 逻辑：参考 huacnlee/disktree

并非所有 Rust 代码都要拆成公开发布的 nshm；disktree 展示了如何在 macOS 与 Linux 应用内部通过 ext/ 让 TSX 直接调用本地高性能 Rust 扫描模块。

浏览社区已发布案例与官方目录清单：查看 longbridge/nsh-showcases

通过 longbridge/nsh-showcases 可参考进入 nsh.dev/apps 与 nsh.dev/directory 的项目元数据格式，与本站 13 个已验证模块形成互补。
